## Структура (вариант Python)

```
src/pcg/bsp.py        генератор 1: BSP-подземелье
src/pcg/cellular.py   генератор 2: клеточные автоматы (пещеры)
src/pcg/validator.py  BFS: проходимость старт→финиш, доля достижимых клеток
src/pcg/stats.py      статистика по 100 уровням → results/stats.csv
src/pcg/render.py     PNG-визуализация 10 уровней (или pygame-просмотр)
```

```bash
pip install -e ".[dev]"
python -m pcg.render --gen bsp --seeds 10      # results/levels/bsp_<seed>.png
python -m pcg.stats --gen bsp --n 100
```

Вариант Unity: создайте проект в `unity/UnityProject/`, портируйте `bsp.py` в `DungeonGenerator.cs`, выводите через Tilemap.

## Как сдавать

1. Работайте в этом репозитории, коммитьте по шагам (`step-1`, `step-2` …) — история коммитов учитывается.
2. Отчёт пишите в `docs/report.md` (черновик по разделам, 5–7 стр.), затем перенесите в официальный шаблон отчёта, принятый на кафедре, и экспортируйте в PDF (`docs/report.pdf`).
3. Видео — на YouTube/Диск, ссылку в README и в отчёт. Файлы видео в git не кладём.
4. Готовую работу отметьте тегом `git tag v1.0 && git push --tags` и создайте Release.
